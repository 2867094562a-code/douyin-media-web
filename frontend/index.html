01 / 连接

静态网页，需要独立后端

GitHub Pages 展示此页面；FastAPI + Playwright 在另一台服务器或你的电脑上运行。未连接时不能解析或下载。

02 / 保存

直链优先，本地保存

可打开、复制源直链。源站跨域限制导致无法另存为时，使用流式保存；服务器不落盘保存媒体。

03 / 权限

尊重作品与访问权限

只整理你有权使用的内容。原图、直链和清晰度以页面实际提供的资源为准，过期后需重新解析。
